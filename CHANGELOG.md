# Changelog

## 1.0.3 - 2026-09-27

- Added default-on Cloud SFX search, preview/download preparation and cloud-source indicators.
- Added After Effects SFX Assistant for animation analysis, reviewed sound suggestions and timed placement.
- Added nested Favorites collections, waveform grid/tile sizing and optional hover audition.
- Added Normalize, Echo and Room Quick FX with preview, bypass and reset.
- Combined waveform and transport into a compact bottom player dock.
- Added a persistent pinned/resizable Library sidebar, compact folder trees and pinned-folder reveal.
- Enabled recursive selected-folder search by default; kept Favorites global.
- Fixed recursive parent counts, toolbar clipping, tooltip bounds and popup stacking above the sidebar.
- Improved virtualized browsing, real waveform placeholders/cache usage, keyboard handling and cloud fallback errors.
- Removed fabricated relevance percentages and fixed the selected-segment Reverse indicator.

See [.github/releases/v1.0.3.md](.github/releases/v1.0.3.md) for full release notes and installation guidance.
