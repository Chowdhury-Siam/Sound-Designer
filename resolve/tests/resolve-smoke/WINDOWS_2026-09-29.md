## API boundary

Resolve 21 exposes current Edit-page transform values through `TimelineItem.GetProperty()`, but does not expose supported enumeration of Edit-page transform keyframes. The assistant therefore uses the supported timeline marker, clip-boundary, and current-clip APIs. Fusion compositions remain a separate host-specific API and are not treated as general Edit-page keyframe data.
